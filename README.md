# MODDY Orders

A small fictional storefront dashboard for screen recording. The sample orders are hard-coded and contain no customer data. The dashboard runs entirely in the browser.

## Preview

Open `index.html` in your browser. Search by order ID or product name, or filter by status. The summary cards show totals across all demo orders.

## Put it on GitHub

Create a private repository named `moddy-orders` and upload the four files inside this folder to the root of the repository. Select that repository when connecting CodeRabbit, if your plan and permissions allow it.

This dashboard has no seeded vulnerability or precomputed scan result. Use a completed finding from an authorised CodeRabbit demo workspace for the reachability and Fix with AI shots.
